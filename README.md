# Dashboard ร้านยา

Dashboard สำหรับร้านยาจำลอง 2 หน้า ใช้ข้อมูลชุดเดียวกัน กดเมนูด้านบนเพื่อสลับหน้า

| หน้า | ทำอะไรได้ |
|---|---|
| [`dashboard01/`](dashboard01/index.html) **บัญชียา & ภาพรวม** | บัญชียา 350 รายการ 16 หมวด แยกตามรูปแบบยาและหมวด และภาพรวมสต็อกรายยา |
| [`dashboard02/`](dashboard02/index.html) **สต็อก · หมดอายุ · สั่งซื้อ · การจ่ายยา** | สิ่งที่ต้องทำวันนี้, ไทม์ไลน์หมดอายุรายล็อต, ใบสั่งซื้อแนะนำ (ดาวน์โหลด CSV ได้), สถิติการจ่ายยา, ความปลอดภัย (จ่ายยาหมดอายุ / หยิบไม่ตาม FEFO), คุณภาพข้อมูล · เลือกช่วงเวลาได้ |

> ข้อมูลทั้งหมดเป็นข้อมูลจำลองเพื่อการเรียน `patient_code` เป็นรหัสแฝง ไม่ใช่ข้อมูลผู้ป่วยจริง

## วิธีเปิด

ดับเบิลคลิก `dashboard02/index.html` หรือ `dashboard01/index.html` ได้เลย ไม่ต้องติดตั้งอะไร

ถ้าเปิดบน GitHub Pages หรือผ่าน local server (`python -m http.server`) หน้าเว็บจะอ่านไฟล์ `.json` โดยตรง

## โครงสร้าง

```
index.html                 หน้าแรก ลิงก์ไปสองหน้า
shared/
  pharma-data.js           ตัวโหลดข้อมูล (ใช้ร่วมกันสองหน้า)
  theme.css                สไตล์ร่วม
dashboard01/index.html     บัญชียา & ภาพรวม
dashboard02/
  index.html               สต็อก · หมดอายุ · สั่งซื้อ · การจ่ายยา
  drugs.json               บัญชียา (ต้นฉบับ)
  stock.json               สต็อกรายล็อต (ต้นฉบับ)
  dispense-log.json        บันทึกการจ่ายยา (ต้นฉบับ)
  data-issues.json         บันทึกการคลีนข้อมูล
  data.js                  สำเนาของไฟล์ JSON สำหรับเปิดไฟล์ตรง (สร้างอัตโนมัติ)
  clean_fix.py             สคริปต์คลีนข้อมูล อ่านจาก cleaned-v1/
  build_data_js.py         สคริปต์สร้าง data.js
  cleaned-v1/              ข้อมูลก่อนคลีนรอบที่ 2
```

## แก้ข้อมูล

แก้ไฟล์ `.json` ใน `dashboard02/` แล้วรัน

```
python build_data_js.py
```

ใน `dashboard02/` เพื่ออัปเดต `data.js` ไม่อย่างนั้นตอนดับเบิลคลิกเปิดจะยังเห็นข้อมูลเก่า (ถ้าแก้ผ่าน `clean_fix.py` สคริปต์จะสร้าง `data.js` ให้เอง)
