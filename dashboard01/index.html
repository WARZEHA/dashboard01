ที่มาของข้อมูล

บัญชียาจาก dashboard02/drugs.json (เวอร์ชัน 2.0): ชื่อสามัญ ความแรง รูปแบบ และรหัส ATC เป็นข้อมูลจริง ส่วนจุดสั่งซื้อเป็นนโยบายสมมติของร้าน

ข้อมูลสต็อก

รวมจาก stock.json ใน dashboard02 นับเฉพาะล็อตสถานะ active ต้นทุนเป็นค่าเฉลี่ยถ่วงน้ำหนัก วันหมดอายุคือล็อตที่หมดเร็วที่สุด

เกณฑ์สถานะ

หมดสต็อก = 0 · ต่ำกว่าจุดสั่งซื้อ = น้อยกว่าจุดสั่งซื้อ · ใกล้จุดสั่งซื้อ = ไม่เกิน 1.5 เท่า · ใกล้หมดอายุ = ภายใน 90 วัน
